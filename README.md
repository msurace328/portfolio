# melissasurace portfolio

Static site. One file, no build step.

## Deploy on Vercel (free)
1. Import this repository at vercel.com (Add New > Project).
2. Leave the settings as they are and click Deploy.
3. Settings > Domains to add a custom .com; Vercel shows the DNS records to set at the registrar.

## Edit
Open index.html. Colors and fonts are the tokens at the top of the <style> block.
